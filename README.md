# Gesture-Controlled Smart Camera

## About the Project

This project presents a gesture-controlled smart camera developed using the XIAO ESP32-S3 Sense. The system uses the onboard camera to recognize hand gestures and control photo capture and video recording without physical buttons. A large hand gesture triggers photo capture, while a hand wave toggles video recording. Captured images and video frames are stored on a MicroSD card, with a GC9A01 TFT display providing a live camera preview.

## Hardware Components

- XIAO ESP32-S3 Sense
- GC9A01 240×240 TFT Display
- MicroSD Module
- 32GB MicroSD Card

## Gestures

- ✋ Large hand → Capture photo
- 👋 Hand wave → Start/stop video recording
- No hand → Live preview
